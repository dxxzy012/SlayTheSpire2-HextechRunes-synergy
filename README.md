## 项目动机

海克斯符文 Mod 拥有 **178+ 枚玩家符文**，但数据分析发现大量符文存在 **低选取率、低持有胜率** 的问题。例如对 13998 局游戏的统计显示：

- 白银品质弱势率 **11.3%**（6 枚符文持有胜率 < 65%）
- 黄金品质弱势率 **25.8%**（16 枚符文持有胜率 < 65%）

**核心思路**：不再单独调整每枚弱势符文的数值，而是通过 **羁绊系统** 将它们与同路线的强力符文捆绑，让凑羁绊的额外收益自然提升弱势符文的价值。

本项目是在原作者 [Natsuki](https://github.com/Natsuki) 的 **海克斯符文** Mod 基础上，基于 13998 局统计数据设计并实现的羁绊平衡方案。

> - 🧩 **原始 Mod**：海克斯符文 v0.5.5（原作者 Natsuki）
> - 📈 **数据基准**：13998 局游戏，整体胜率 47.3%
> - ⚙️ **本仓库新增**：11 个羁绊系统 + 权重机制 + 数据驱动的分组策略

## 平衡思路

### 数据驱动分组

基于选取率与持有胜率统计，将弱势符文编排进不同羁绊路线，使其与同路线强势符文共享羁绊激活收益，间接提升选取意愿。

| 以金币雨羁绊为例 | 选取率 | 持有胜率 | 羁绊效果 |
|:---|:---:|:---:|:---|
| 收集者 | 43.9% | 62.6% | 金币获取 +30% |
| 献祭 | 41.4% | 59.8% | 每回合 5 金币换 1 能量 |
| 红包 | 59.1% | 59.8% | → 弱符文被"绑大腿" |
| 夺金 | ... | ... | 凑 2 枚即可激活羁绊 |
| 星河馈赠 | 43.2% | 52.9% | ← 弱符文得到价值提升 |

### 权重导向

通过权重加成机制，让已拥有某羁绊符文的玩家在后续选择中更大概率遇到同羁绊选项，形成正向循环。

## 项目特点

- 🎯 **数据驱动的分组策略** —— 基于 13998 局选取率与持有胜率统计，设计 11 条羁绊路线将弱势符文与强势符文捆绑
- ⚖️ **权重加成机制** —— 拥有某羁绊 1 枚符文时，同羁绊符文后续出现权重提升至 **2 倍**；拥有 2 枚且该羁绊有 3 件效果时提升至 **3 倍**
- 🧬 **11 条羁绊路线** —— 金币雨、掷骰狂人、锻体熔炉、叠角龙、苦痛回响、小巨人、决斗大师、大法师、远古龙魂、赏金猎人、卡牌大师
- 👁️ **门槛预览系统** —— 符文选择界面实时展示羁绊进度（✓/○），并可预览"选择此符文后的状态"
- 🗺️ **全地图悬浮提示** —— 任意已拥有符文上悬浮即可查看羁绊进度与门槛详情
- 🏷️ **彩色羁绊徽章** —— 符文卡片上显示颜色徽章：🔴已激活 / 🟡进行中 / 🟢未触发
- 🔄 **刷新保留权重** —— 重随系统同样应用权重加成，刷新不丢失羁绊倾向
- 🔗 **双层映射容错** —— 符文到羁绊识别支持类型匹配 + ID/名称回退匹配
- 👥 **多人联机同步** —— 脏标记自动重算 + 稳定随机种子保证联机一致性
- 📐 **标准化扩展** —— 以金币雨为模板，新增羁绊只需定义符文类型列表和阈值效果
